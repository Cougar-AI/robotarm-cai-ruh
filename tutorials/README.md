# Tutorials and Documentation for Robot Arm Project CougarAIxRobotics@UH (FA25 - SP26)

**This project is under active development.**

Currently, `IsaacSim`, `MuJoCo`, and `ROS2 + Gazebo` tutorials are available.

## MuJoCo
For setting up a **Mu**lti-**Jo**int dynamics with **Co**ntact (MuJoCo) interactive viewer please see [mujoco/MUJOCO_VIEWER.md](mujoco/MUJOCO_VIEWER.md).

For setting up MuJoCo with ROS2 control and MuJoCo's viewer, please see [mujoco/MUJOCO_ROS2.md](mujoco/MUJOCO_ROS2.md)

MuJoCo is developed and maintained by Google DeepMind [GitHub](https://github.com/google-deepmind/mujoco)

## ROS2 + Gazebo
For setting up ROS2 + Gazebo on Jetson (Linux first, WSL2 notes, macOS caveat), see [ROS2_GAZEBO.md](ros2/ROS2_GAZEBO.md).

The ROS2 tutorial also includes:
1) `tutorials/ros2/init_workspace.sh` for a general custom-arm workspace layout
2) `tutorials/ros2/ur3_demo.sh` for a UR3 simulation + planning + scene-assets demo

## IsaacSim
For setting up NVIDIA IsaacSim please see [isaacsim/ISAACSIM_VIEWER.md](isaacsim/ISAACSIM_VIEWER.md)
